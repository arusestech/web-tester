# SCBK VOC — SIT 온라인 시나리오 (폐쇄망 수행, 인터페이스 제외본)

SIT 문서 v0.6 의 케이스 ID = 파일명. **파일은 생성기로 만든 것**이라 구조를 바꿀 일이 있으면 반출 요청 후 개발 PC 에서 재생성한다.
회차·환경 값은 파일을 고치지 않고 아래 두 곳에서만 바꾼다.

2. **`01_SIT_온라인/_공통.json` → 테스트 데이터(변수)** (GUI 편집 탭에서 `_공통.json` 을 열어 수정)

## 데이터 전제

## 폐쇄망 주의
- **외부 연계를 호출하지 않는다** — 고객정보확인(MCI) 버튼을 누르는 흐름이 없다. 고객명은 더미(TEST_고객).
- **SIT 배치가 돌고 있으면 통보가 실제로 발송된다.** 그래서 모든 등록·처리에서 접수회신/고객회신 **'통보없음'** 을 체크하고, 체크가 안 됐으면 버튼을 누르기 전에 흐름을 실패로 멈춘다. 직원 통보(배정·확정 등)는 SIT 계정 메일로 나갈 수 있으니 계정 메일주소를 확인해 둔다.
- 증적 스크린샷은 고객 입력칸·로그인 사용자명을 마스킹한다. 증적은 망 안에서 ADO 에 첨부하고 반출하지 않는다.
- 엑셀 다운로드 파일 내용 대조는 망 안에서 수동.
- forbidden: 발송·재발송·전송·삭제·폐기·강제실행·반려·반송·즉시처리·마스터 전달·일괄. SIT 스텝의 폐기/마스터 전달/반송은 `expectFail` → 버튼 노출까지 확인하고 🔒(예상된 실패)로 집계. 실제로 누르려면 승인 후 해당 흐름에 `allowForbidden` 추가.
- 스텝 안의 `#__wwt_var` 는 테스터가 변수를 스크립트에 넘기려고 잠깐 만드는 입력칸이다(사용 직후 제거, 스크린샷 마스킹).
