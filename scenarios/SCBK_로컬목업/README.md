# SCBK VOC — SIT 온라인 시나리오 (로컬 목업 버전)

`SCBK` 프로젝트(폐쇄망용)와 **흐름은 똑같고 환경값만 다른** 개발 PC 확인용이다. 생성기로 만든 파일이라 직접 고치지 않는다.
- 접속: `http://localhost:9090` (IntelliJ Tomcat 11). WildFly 로 띄웠으면 🔧 프로젝트 설정에서 `:8180`
- 계정: 개발DB `sit_*` 11개 + `admin` (vars 에 기본값). 비밀번호만 실행 시 입력 — **09-17 개발DB 조회로 확인: 12개 모두 존재·사용 가능(STATUS 00, 로그인 허용, 실패횟수 0), 비밀번호 전부 1234**

- 회차 마커 기본 `TEST_LOCAL04` — 다시 돌릴 때 `_공통.json` vars 의 mark 를 바꾼다 (01~03 은 09-17 실행에서 사용)
- **개발DB 부서 928건의 STATUS 가 비어 있어(NULL) 부서 검색이 0건** → 확정 단계부터 막힌다. 09-17 `STATUS='A'` 보정 완료. `DEPT_NM_FULL` 도 비어 있어 처리부서 팝업 부서 목록 글자가 공란으로 보인다(선택은 가능)
- 고객정보: MCI 목업 고객값이 vars 에 들어 있어 실행 시 묻지 않는다 (생년월일 1990-01-01 / 휴대폰 010-0000-0001 → 고객분류 PB)

## 사전 준비
1. 서버 기동 (9090) — 로그인 화면 `/screen/BCO0001.ub` 확인
2. **MCI 목업 기동**: 08-22 CRUD 흐름 테스트 폴더의 `mci_mock.py` (127.0.0.1:8330) 를 실행하고,
   배포본(exploded) `MCI.properties` 의 IP 를 127.0.0.1 로 바꾼다 (소스는 변경하지 않음). MCI 는 TCP 전문이라 테스터의 HTTP stub 으로는 대신할 수 없다
3. 배치 데몬은 띄우지 않는다 (통보는 TBS_DISPATCH_RUN 적재까지만)
4. 개발DB 에 테스트 데이터가 남는다 — 정리는 제목 마커(mark) 기준으로 하고 SQL 실행 이력을 남긴다

## 실행
- 인터페이스 제외: `node cli.js run scenarios\SCBK_로컬목업\01_SIT_온라인`
- MCI 포함: 이어서 `node cli.js run scenarios\SCBK_로컬목업\02_SIT_인터페이스` (MCI 목업 기동 필요)

폴더 구성·데이터 흐름·잠정값 목록은 폐쇄망용 `SCBK/README.md` 와 같다.
