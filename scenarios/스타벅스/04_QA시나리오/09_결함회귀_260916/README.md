## ⚠️ TC_683 은 결함이 아닐 수 있다

`VOC1103.jsp:179~206` 기준, 상태를 완료(99)로 바꿀 때 **고객정보 입력창(`#INDVDLINFO`)은 요청유형(`CD_REQEST_TY`)이 `'2'`(고객정보 요청)일 때만** 노출된다.
요청유형이 2 가 아닌 건을 골랐다면 미노출이 정상 동작이다.
시나리오는 요청유형을 먼저 읽어 그에 맞게 판정하고, 2 가 아니면 `document.title` 에 참고 문구를 남긴다.
메모 입력창(`#layout-1_7`)은 상태가 `'01'`(요청중)만 아니면 노출되어야 하므로 이쪽은 그대로 검증한다.
