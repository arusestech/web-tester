## A. 트리 화면 — 수정함, 재확인만 (2개)

소스 JSP 의 숨겨진 검색폼(`#searchForm`/`#rb_store`)을 잘못 넣어 첫 실행에서 ❌ 났던 것을,
스크린샷에서 실제로 보이는 **트리 컨테이너**로 교체했다. 재실행하면 ✅ 여야 한다.

| 화면 | URL | 현재 expect | 확인 |
|---|---|---|---|
| VOC 분류관리 | `/screen/VOC1026.ub` | `#vocCauseTree` | 트리(분류구조/Menu) + 분류상세폼이 뜨면 ✅ |
| 스토어 케어 분류관리 | `/screen/STC0102.ub` | `#storecareCauseTree` | 트리 + 상세폼이 뜨면 ✅ |

**빠른 확인** (메뉴회귀 파일에서 이 둘만):
```
run.bat scenarios\스타벅스\01_메뉴회귀\starbucks-voc.json --only "VOC 분류관리" --headless --screenshot all
run.bat scenarios\스타벅스\01_메뉴회귀\starbucks-voc.json --only "스토어 케어 분류관리" --headless --screenshot all
```
→ 여전히 `핵심 요소 없음: #vocCauseTree (N초 대기)` 가 나오면, 스크린샷을 열어 실제 보이는 요소 id 로 바꾼다.

## B. 팝업 화면 — 미실행, 소스 기반 expect (2개)

`window.open` 팝업을 직접 URL 로 여는 것이라 렌더가 다를 수 있다. expect 는 소스에서 뽑은 잠정값.

| 화면 | URL | 현재 expect | 확인 / 대안 |
|---|---|---|---|
| 결재상신등록 (조회만) | `/screen/APP0003.ub` | `#APPROVAL_FORM` | 결재 상신 폼이 뜨면 ✅. 안 뜨면 스크린샷의 실제 폼/입력 id 로 교체. 포함: `02_권한/auth-P01-R100.json` |
| 문자발송 (조회만) | `/screen/POP0007.ub` | `#registForm` | 문자 발송 폼(수신자+내용 `#DS_CONTENT`)이 뜨면 ✅. 안 뜨면 `#DS_CONTENT` 로 교체. 포함: `02_권한` 7개 파일 |

**빠른 확인**:
```
run.bat scenarios\스타벅스\02_권한\auth-P01-R100.json --only "결재상신등록" --headless --screenshot all
run.bat scenarios\스타벅스\02_권한\auth-P01-R100.json --only "문자발송" --headless --screenshot all
```
> ⚠️ 실행돼도 **발송/상신 버튼은 forbidden 으로 차단**되니 실제로 나가지 않는다. 화면이 뜨는지만 본다.

## C. JSP 부재 화면 — 뷰 없음 (2개)

`APP5001.jsp`·`APP5005.jsp` 가 소스·개발 배포본 어디에도 없었다(APP0001~0011 만 존재).
사외 기준으론 접근 시 오류가 정상이라 expect 를 넣지 않고 `_note` 만 달았다.
**사내 배포본에는 있을 수 있으니** 실행해서 확인한다.

| 화면 | URL | 확인 |
|---|---|---|
| 상신함 | `/screen/APP5001.ub` | 렌더되면 → 목록 그리드 id(예: `#list`)를 expect 로 추가 / 여전히 "시스템 오류" 면 뷰 부재 확정 → `_note` 유지 |
| 결재함 | `/screen/APP5005.ub` | 동일 |

포함: `02_권한/auth-P01-R100.json`. `errorPatterns`(시스템 오류 등)가 붙어 있어 오류면 ❌ 로 자동 감지된다.

## D. 아직 사내에서 한 번도 안 돌린 것

이번엔 **메뉴회귀(01)만** 실행했다. 아래는 사내 첫 실행 대상.

- **02_권한 (24 페르소나)**: 계정 `TEST_R110~R999`(비번 실행 시 입력). 각 계정이 보는 메뉴가 맞는지 = 권한 매트릭스 검증.

  run.bat scenarios\스타벅스\02_권한 --mode menus --headless --secret password=***
