# 스타벅스_내부 — 내부망 실행용

내부망(POD/개발서버)에서 QA 결함 40건 회귀를 돌리기 위한 프로젝트다.
시나리오 본문은 복제하지 않고 `스타벅스/04_QA시나리오/09_결함회귀_260916/` 을 `extends` 로 쓴다.
이 폴더가 바꾸는 것은 **접속 주소뿐**이다(외부연동이 실제로 살아 있으므로 stub 은 OFF).

```
09_결함회귀_260916/*.json   ← 얇은 래퍼 5개 (extends 로 본문 상속)
_project.json               ← baseUrl 플레이스홀더, stubServer OFF
```

## 🔴 반입할 때 같이 가져가야 하는 것

래퍼가 `extends` 로 본문을 참조하므로 **아래 셋이 다 있어야 동작한다.** 하나라도 빠지면 상속이 깨진다.

```
web-tester/                                   ← 도구 본체 (node_modules, playwright 브라우저 포함)
  scenarios/스타벅스/_project.json
  scenarios/스타벅스/04_QA시나리오/_공통.json
  scenarios/스타벅스/04_QA시나리오/09_결함회귀_260916/   ← 시나리오 본문 + _files/
  scenarios/스타벅스_내부/                              ← 이 폴더
```

`스타벅스/_project.json` 의 baseUrl(사내 개발서버)은 이 프로젝트에 영향을 주지 않는다 —
실행 시에는 **자기 프로젝트(`스타벅스_내부/_project.json`)의 값이 쓰인다.**

첨부 업로드 TC(099·651·1427)가 쓰는 파일은 도구 폴더 기준 상대경로로 지정돼 있다:
`scenarios/스타벅스/04_QA시나리오/09_결함회귀_260916/_files/TEST_QA_첨부.txt` — 이 파일도 함께 반입할 것.

## 반입 후 1회 설정

`_project.json` 의 `baseUrl` 한 줄만 내부 실제 주소로 바꾼다. **컨텍스트 경로까지** 적는다.

```json
"baseUrl": "http://dev-ivoc.istarbucks.co.kr:8888"
```

- 로그인 화면이 `<baseUrl>/screen/BCO0001.ub` 로 열리면 맞게 넣은 것이다.
- 컨테이너(POD) 배포는 ROOT 컨텍스트라 호스트·포트만 적는다. WAS 배포면 `/voc` 같은 컨텍스트가 붙는다.
- 브라우저는 `channel` 을 비워 뒀다 → Chrome 이 없으면 Edge 로 자동 선택된다.

## 실행

```
cd <web-tester>
set WWT_password=<test01 비번>
run.bat scenarios\스타벅스_내부\09_결함회귀_260916 --screenshot fail
```

처음에는 창을 띄운 채(기본) 로그인까지 눈으로 확인하고, 그다음부터 `--headless` 를 붙인다.
한 건만: `run.bat scenarios\스타벅스_내부\09_결함회귀_260916\04_VOC설정.json --only VC_TC_1306`
실패한 것만 다시: `--rerun-failed`

## 🔴 데이터를 바꾸는 흐름이 8건 있다

사용자 승인 하에 `allowForbidden` 으로 포함한 흐름이다. **내부 개발서버의 실데이터가 바뀐다.**

| TC | 남는 것 |
|---|---|
| `VC_TC_1236` / `1245` | VOC 배분관리에 배분자 **각 1건 생성** → 실행 후 VOC1024 에서 삭제 |
| `VC_TC_655` / `1204` / `1267` | 정상이면 알림으로 막힘. **결함이 남아 있으면** 각 1건 생성 |
| `VC_TC_1327` / `1339` / `1408` | 현재 값을 그대로 다시 저장 → 내용 변화 없음 |
| `VC_TC_1083` | **CE 마감 점수 업로드를 실제로 실행** — 대상 월 확인 후 돌릴 것 |

빼고 돌리려면 그 항목만 제외하거나, 조회성만 골라 `--only` 로 돌린다.
각 흐름이 무엇을 하는지는 `스타벅스/04_QA시나리오/09_결함회귀_260916/README.md` 의 표에 정리돼 있다.
