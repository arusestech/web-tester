## 화면 구조 메모 (시나리오를 고칠 때 필요)

- 검색폼은 둘로 나뉜다: `#vocSearchFrm` + `#addtFrm > .moreBox`. 개선7 로 추가한 14종은 전부 `.moreBox` 안이다.
  **`.moreBox` 는 화면을 열면 이미 펼쳐져 있다**(`common.css` 의 `display:none` 이 실제 렌더에서는 `flex` 로 덮인다).
  `.moreBtn`("상세검색")을 누르면 **접힌다** — 그래서 시나리오는 클릭 대신
  "닫혀 있을 때만 연다"는 eval 스텝을 쓴다. 처음에 클릭 스텝을 넣었다가 필드가 사라져 전부 timeout 났다.
- `channelWrapper`(접수경로)·`typeWrapper`(VOC구분)·`tgtWrapper`(발생원인)는 select 가 아니라
  **자동완성 입력 + 조회 버튼 + hidden** 방식이라 select 관련 검사에서 자동으로 제외된다.
- 관리코드 항목은 `<div id="xxxWrapper" class="selectWrapper" data-name="파라미터명" data-comn-cd="NNN">` 이고,
  `voc-1.js` 가 AJAX 로 `<select name="파라미터명">` 을 만들어 붙인다. 1단계를 고르면 **같은 name 의 2단계 select** 가 추가된다.
- 그래서 폼 직렬화만으로는 1단계 값이 사라진다(`setParamValue` 가 마지막 값을 쓰는데 2단계가 비어 있음).
  `getWrapperValToParam(param, SEARCH_WRAPPER_IDS)` 가 이를 되살린다 — 03 파일이 검증하는 지점이 여기다.
- 조회 버튼 `a.btn-search`(onclick=`loadGrid()`), 엑셀 `a[data-click=excelDownload]`, 그리드 `#divGrid1`(toastUI).
